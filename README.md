# Каталог фильмов (Movie Catalog)

Мини-приложение для ведения личной фильмотеки, разработанное на **Python** с использованием графической библиотеки **PyQt6** и реляционной базы данных **SQLite**.

---

## Основные возможности

- **Управление коллекцией:** Добавление новых фильмов, подробное редактирование и удаление записей.
- **Гибкая структура данных:** Нормализованная база данных (с таблицами «многие ко многим») для жанров, стран и режиссёров.
- **Обязательные и опциональные поля:** 
  - *Обязательные:* Название фильма, Жанр(ы).
  - *Опциональные:* Год выпуска, Страна/ы, Режиссёр/ы, личный отзыв и оценка (интерактивный слайдер от 0 до 10).
- **Категории просмотра:** Распределение фильмов по статусам:
  -  *В планах*
  -  *Смотрели*
  -  *Избранные*
  -  *Брошенные*
- **Сортировка и фильтрация:** 
  - Выбор категории для просмотра конкретного списка.
  - Сортировка списка по алфавиту (название А-Я), дате добавления, году или оценке.
- **Карточка фильма:** Двойной клик по любой строке открывает подробное окно с полной информацией и вашим отзывом.
- **Надежное хранение:** Все данные автоматически сохраняются в локальную базу данных SQLite (`movies_normalized.db`).

---

##  Структура проекта

Проект разделен на логические модули:

```text
 movie-catalog/
│── main.py                # Главный файл: графический интерфейс (PyQt6) и логика взаимодействия
│── database.py            # Модуль базы данных: подключение, создание таблиц и SQL-запросы (SQLite)
│── requirements.txt       # Список зависимостей для установки библиотек
│── movies.db              # Файл базы данных (создается автоматически при первом запуске)
└── README.md              # Документация проекта
```
---

##  Технологии

- **Python 3.10+**
- **PyQt6** — для построения графического интерфейса
- **SQLite3** — для надежного хранения данных в локальной базе

## Установка и запуск

### Способ 1: Быстрый запуск (через готовый .exe)
1. Убедитесь, что исполняемый файл и файл базы данных (`movies.db`) находятся в одной папке.
2. Дважды кликните по `main.exe` для запуска программы.

### Способ 2: Запуск из исходного кода (через Python)
1. Установите необходимые библиотеки из файла зависимостей:
   ```bash
   pip install -r requirements.txt
2. Запустите главный файл приложения:
```text
python main.py
